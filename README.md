# 📚 Student Study Planner

A simple and responsive web application that helps students organize study sessions, track completed sessions, monitor study progress, and filter sessions by subject.

## ✨ Features

- Add study sessions
- Enter subject, topic, date, and duration
- Mark sessions as completed or pending
- Delete study sessions
- Track completion percentage
- View study statistics
- Filter sessions by subject
- Store sessions using browser localStorage
- Responsive design for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage
- Git
- GitHub

## 📊 Statistics

The application displays:

- Total study sessions
- Completed sessions
- Pending sessions
- Total study minutes
- Completion progress

## 🚀 How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a browser.
